# Rijad Portfolio

A clean, responsive, and performance-optimized personal portfolio and interactive interactive CV. This workspace-grade single-page application is designed to showcase academic achievements, mathematical frameworks, and professional history in a compact, highly scanable layout.

## Core Features

- **Interactive Standard & Technical CV Views**: Toggle seamlessly between standard professional views and an audit-ready technical view designed for technical roles.
- **Tailwind Grid & Fine Typography**: Fluid, modern spacing integrating Inter and system sans-serif font families for maximal reading comfort.
- **Interactive Recruiter Mailer**: A lightweight, pre-composed email composer allowing direct and streamlined communication with prospective employers.
- **Print Optimized Layout**: Includes dedicated CSS printing properties custom-tailored to produce a beautiful, standard two-page physical resume.

## Technologies Used

- **React 18** with **Vite**
- **TypeScript**
- **Tailwind CSS**
- **Lucide React** for minimal iconography
- **Motion** for subtle transitions and interactive cues
